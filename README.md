# Gestion d'Étudiants

Ce projet est une application de gestion d'étudiants permettant de gérer les informations des étudiants, leurs cours, et leurs résultats.

## Fonctionnalités

- Ajouter, modifier et supprimer des étudiants.
- Gérer les cours et les inscriptions.
- Suivre les résultats académiques des étudiants.
- Générer des rapports.

## Prérequis

- **Serveur Web** : XAMPP, WAMP ou tout autre serveur compatible PHP.
- **Base de données** : MySQL.
- **Langage** : PHP, HTML, CSS, JavaScript.

## Installation

1. Clonez ce dépôt :
    ```bash
    git clone https://github.com/votre-utilisateur/gestion_etudiants.git
    ```
2. Placez le projet dans le répertoire `htdocs` de XAMPP.
3. Importez le fichier `database.sql` dans votre base de données MySQL.
4. Configurez le fichier `config.php` avec vos informations de base de données.
5. Lancez le serveur XAMPP et accédez à l'application via `http://localhost/gestion_etudiants`.

## Utilisation

1. Connectez-vous à l'application.
2. Ajoutez des étudiants et des cours.
3. Gérez les inscriptions et suivez les résultats.
